# RepoWayfinder MB：有证据的部署助手

核心流程是仓库获取、入口分析、环境准备、依赖安装、启动验证和报告续跑。每个启动入口保留配置文件及行号；每个执行步骤使用结构化参数，不直接执行模型返回的 shell 文本。

Windows 原生程序负责流程编排，可选 AI 负责解释上下文与推荐已有路线。文件读取、进程、环境生命周期、仓库来源及模型接口有独立模块，扫描库也可单独使用。

缺少依赖时先进入环境等待；真实命令失败后才提供失败诊断。HTTP 验证和程序正常退出分别记录，进程存活本身不构成成功。

使用说明见 [README](../README.md)，实际验收范围见 [验证记录](verification.md)。
